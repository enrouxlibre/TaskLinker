# TaskLinker

## Français

TaskLinker est un projet de développement web réalisé dans le cadre d’un projet OpenClassrooms.

Ce projet a pour objectif de mettre en pratique les compétences de création d’applications web modernes, notamment avec Symfony, Twig, Doctrine et une architecture MVC.

Il s’agit d’une application de gestion de tâches et de projets, conçue pour illustrer le fonctionnement d’un site web dynamique avec une interface utilisateur simple et efficace.

### Fonctionnalités principales

- Gestion des projets
- Gestion des tâches
- Gestion des utilisateurs
- Interface web responsive

### Technologies utilisées

- PHP / Symfony
- Twig
- Doctrine ORM
- PostgreSQL
- HTML / CSS / JavaScript

### Lancer le projet

1. Installer les dépendances avec Composer
2. Configurer la base de données dans le fichier .env
3. Exécuter les migrations
4. Démarrer l’application Symfony

## English

TaskLinker is a web development project created as part of an OpenClassrooms project.

The goal of this project is to put into practice the skills needed to build modern web applications, especially using Symfony, Twig, Doctrine, and an MVC architecture.

It is a task and project management application designed to demonstrate how a dynamic website works with a simple and effective user interface.

### Main features

- Project management
- Task management
- User management
- Responsive web interface

### Technologies used

- PHP / Symfony
- Twig
- Doctrine ORM
- PostgreSQL
- HTML / CSS / JavaScript

### Run the project

1. Install dependencies with Composer
2. Configure the database in the .env file
3. Run the migrations
4. Start the Symfony application
